# Lesson 36 話法 練習帳 — GitHub公開セット

## 最初に：ZIPは解凍してからアップロード

1. このZIPをPCで「すべて展開」する。
2. GitHubで公開用リポジトリを開く（新規なら、例として `lesson36` を作る）。
3. **Add file → Upload files** を押す。
4. 展開したフォルダーの**中身すべて**をアップロードする。ZIP自体や外側のフォルダーをそのままアップロードしない。
5. **Commit changes** で保存する。同名ファイルがある場合は更新する。
6. **Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save**。
   別のブランチにアップロードした場合は、そのブランチを選ぶ。
7. 公開処理が完了したら、Pages画面の **Visit site** を開く。そのURLを生徒に共有する。

リポジトリの最初の画面で `index.html` と `README.md` と `assets` が見えれば、置き場所は正しい。
`github.com/.../blob/.../index.html` はソース表示。アプリのURLは Pages画面で確認する。
例： `https://ユーザー名.github.io/lesson36/` （実際のURLに置き換える）

## 入っているファイル

- `index.html`：アプリ本体。トップページとして自動表示。
- `jindex.html`：以前の名前で開いた場合に本体へ移動。
- `assets/`：5キャラクターの画像。フォルダーごと必須。
- `manifest.webmanifest`：ホーム画面用の設定。
- `sw.js`：以前のキャッシュ優先処理を置き換えるためのワーカー。オフライン保存はしない。
- `.nojekyll`：静的ファイル用。隠しファイルとして見えない環境では、なくてもこの構成は表示可能。
- `README.md`：この説明書。

## iPhone・Android・PCでの使い方

公開URLをiPhoneのSafari、AndroidのChrome、PCのChrome・Edge・Safari・Firefoxで開く。
学校アプリやTeams内の画面でうまく動かないときは、URLを通常のブラウザで開く。
スマートフォンは縦画面に対応。選択・並べ替えはタップ、英文はキーボード入力。
ホーム画面への追加は各ブラウザの共有／メニューから行う。利用には通信が必要。
音は画面操作後に再生される。鳴らなければ音ボタン・端末音量・消音設定を確認。
進捗・キャラクター・訪問日数は同じ端末・同じブラウザに保存。端末間の同期はない。
保存を禁止しているブラウザでは記録を保持できない。都立AIは別タブで開き、質問を貼り付ける。
パスワードはこれまでと同じ。これは画面上の簡易ロックで、サーバー認証ではない。

## 表示されない場合

- 404：`index.html` が公開ブランチの一番上にあるか、Pagesが `/(root)` かを確認。
- 画像がない：`assets` フォルダーもアップロードする。名前の大文字小文字を変えない。
- 古い画面：Pages公開処理の完了後に再読み込みする。以前のタブを閉じて開き直す。
- 更新前のキャッシュが残る：プライベートウィンドウでURLを確認。通常ブラウザのサイトデータ削除は進捗も消すため最終手段。
- 公開失敗：リポジトリの **Actions** を開き、赤い実行結果を確認。
